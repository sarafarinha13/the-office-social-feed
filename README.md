# The Office Social Feed

Red social interactiva inspirada en The Office desarrollada con HTML, CSS y JavaScript.

## Funcionalidades

- Publicación de posts dinámicos
- Sistema de likes interactivo
- Generación automática de publicaciones
- Animaciones CSS
- Feed en tiempo real
- Diseño inspirado en redes sociales

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- Flexbox
- Font Awesome

## Conceptos trabajados

- Manipulación del DOM
- Eventos (`addEventListener`)
- Creación dinámica de elementos
- Arrays y objetos
- Funciones
- Animaciones CSS
- Temporizadores (`setTimeout`)
- Responsive design

## Funcionamiento

La aplicación genera publicaciones dinámicamente mediante JavaScript utilizando `createElement()` y manipulando el DOM. :contentReference[oaicite:0]{index=0}

Los usuarios pueden publicar mensajes, dar likes y visualizar posts automáticos generados aleatoriamente. 

El diseño utiliza Flexbox, animaciones y estilos personalizados inspirados en The Office.
